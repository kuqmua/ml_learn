# 246 · MNIST: Свёрточная нейросеть для PNG

Сохрани двумерную структуру изображения: обучай общие фильтры, которые ищут локальные штрихи в разных местах. CNN состоит из двух обучаемых свёрток, двух pooling и двух Dense, всего 27 690 параметра.

| Операция | Форма одного примера |
|---|---|
| Вход PNG | 1×28×28 |
| Conv 5×5, 8 фильтров, valid → ReLU | 8×24×24 |
| Max-pool 2×2, шаг 2 | 8×12×12 |
| Conv 3×3, 16 фильтров, valid → ReLU | 16×10×10 |
| Max-pool 2×2, шаг 2 | 16×5×5 |
| Flatten → Dense(64) → ReLU | 64 |
| Dense(10) → softmax loss | 10 |

Одна матрица фильтров используется во всех позициях окна: меньше параметров и одинаковый способ распознавания локального признака. После pooling ширина и высота уменьшаются вдвое. Обратный проход идёт через оба pooling, ReLU и обе свёртки; обновляются все фильтры, Dense и смещения. Это полноценное обучение CNN с исходных PNG, не фиксированная извлечённая характеристика.

Смотри архитектуру и порядок обратного прохода в функции `main` файла `src/main.rs`, а реализацию im2col и суммирования градиентов перекрывающихся окон — в этом же файле.

## Запуск

Из папки урока:

```bash
python3 ../scripts/prepare_mnist.py
cargo run
```

Настройки в начале `main`: 12 эпох, batch-size 64, learning-rate 0.001, seed 42, полный train. Обучение идёт на CPU. Обычный `cargo run` использует оптимизацию, настроенную в корневом Cargo.toml.

[Правила эксперимента и сравнение моделей](../MNIST.md) описывают загрузку PNG, разделение данных, Adam и параметры обучения. Метка берётся из имени папки, 784 пикселя нормализуются делением на 255. Каждый пятый PNG каждого класса используется для validation; test не участвует в обучении и выборе эпохи.

Вывод содержит train loss, validation loss и accuracy по эпохам, выбранную по validation loss эпоху, итоговый test и матрицу ошибок. Результат не гарантирован одной архитектурой: важны данные, скорость обучения и число эпох.

## Самостоятельное задание

1. Рассчитай размеры карт после каждой операции без запуска. Почему первая свёртка даёт 24, а не 28?
2. Для окна pooling [[1,3],[2,4]] и входящего градиента 2 вычисли результат и четыре градиента по пикселям.
3. Объясни, почему градиенты перекрывающихся свёрточных окон складываются.
4. Измени `epochs` в начале `main` на 1, затем верни 12. Сравни время обучения и метрики.
5. Сравни CNN с MLP по validation loss, test accuracy и числу параметров. Почему меньше параметров не обязательно означает меньше вычислений?
6. Просмотри неправильно распознанные PNG. Для дальнейшего улучшения сравни больше фильтров или другой learning-rate на validation; не подбирай их по test.

Урок пройден, если можешь объяснить прямой и обратный проход модели, какие параметры обучаются, почему выбор эпохи идёт по validation и как проверить метрику на настоящих PNG.

Проверенный полный запуск с настройками по умолчанию: **98,81% accuracy на test**. [Сравнение и журналы запусков](../MNIST.md#проверенный-запуск-на-полном-mnist).

В уроке объявлена только функция `main`: загрузка PNG, числовые операции, параметры, обучение и оценка находятся внутри неё. Для повторяющихся операций используются локальные замыкания. Путь к данным и настройки заданы в коде. Запуск без аргументов загружает MNIST, обучает модель и выводит метрики.

# Понятия перед кодом: блоки 01–06

Этот конспект читай **до запуска** соответствующего пакета. В каждом пункте есть смысл, маленький расчёт и ошибка, которую легко допустить. После чтения закрой пример, воспроизведи расчёт на бумаге и только потом запускай код. Задание для изменения программы находится в [самопроверке](SELF_CHECK.md).

## 01. Векторы и геометрия

**001. Попарное умножение и сумма.** Берём числа на одинаковых местах: `[1, 2] · [3, 4] = 1·3 + 2·4 = 11`. Знак результата помогает судить об угле ненулевых векторов. Ноль бывает и у перпендикулярных векторов, и при нулевом векторе; эти случаи нужно различать. [Код](part-001-lesson-01-multiply-coordinates-and-add/).

**002. Норма L1.** Складываем модули координат: для `[-3, 4]` получаем `3 + 4 = 7`. Отрицательная координата не уменьшает длину. Не путай L1 с обычной длиной стрелки. [Код](part-002-lesson-01-l1-norm/).

**003. Норма L2.** Квадраты координат складываются, затем извлекается корень: `√(3² + 4²) = 5`. Это расстояние от начала координат до конца вектора. Забытый корень дал бы квадрат длины, 25. [Код](part-003-lesson-01-l2-norm/).

**004. Расстояние.** Сначала вычитаем координаты точек, затем берём L2: между `[1, 2]` и `[4, 6]` разность `[3, 4]`, расстояние `5`. Порядок точек на ответ не влияет. [Код](part-004-lesson-01-distance/).

**005. Косинусное сходство.** Делим скалярное произведение на обе длины. `[1, 0]` и `[2, 0]` дают `1`: направления совпадают, несмотря на разные длины. Для нулевого вектора делить нельзя. [Код](part-005-lesson-01-cosine-similarity/).

**006. Сводная практика.** Одну пару векторов можно описать разными числами: скалярное произведение учитывает длины и угол, косинус выделяет направление, расстояние сравнивает концы стрелок. Перед вычислением проверь одинаковое число координат. [Код](part-006-lesson-01-vectors/).

## 02. Матрицы

**007. Форма.** У матрицы из двух строк по три числа форма `2×3`: сначала строки, потом столбцы. Строка другой длины нарушает прямоугольную форму; перед вычислением это нужно отклонить. [Код](part-007-lesson-02-matrix-shape/).

**008. Транспонирование.** Строки становятся столбцами: `[[1, 2, 3], [4, 5, 6]]` превращается в `[[1, 4], [2, 5], [3, 6]]`. Форма `2×3` становится `3×2`. Двойное транспонирование возвращает исходную матрицу. [Код](part-008-lesson-02-transpose/).

**009. Матрица на вектор.** Каждая строка даёт одно скалярное произведение: `[[1, 2], [3, 4]] · [5, 6] = [17, 39]`. Число столбцов матрицы должно равняться длине вектора. [Код](part-009-lesson-02-matvec/).

**010. Матрица на матрицу.** Элемент результата — скалярное произведение строки левой и столбца правой матрицы. Для форм `2×3` и `3×4` результат имеет форму `2×4`; внутренние размеры должны совпасть. [Код](part-010-lesson-02-matmul/).

**011. Система уравнений.** Решение — значения, которые удовлетворяют *обоим* уравнениям. Для `x+y=5`, `x−y=1` получаем `x=3`, `y=2`; подставь их обратно для проверки. Одного верного уравнения недостаточно. [Код](part-011-lesson-02-linear-system/).

**012. Сводная практика.** Храни форму вместе с данными и проверяй её до умножения. Единичная матрица действует как число `1`: `I·A=A`, если формы совместимы. [Код](part-012-lesson-02-matrices/).

## 03. Производные

**013. Производная.** Она показывает локальный наклон функции. Для `f(x)=x²` производная `2x`: в точке `3` наклон `6`, в точке `−2` — `−4`. Нулевая производная сама по себе не доказывает минимум. [Код](part-013-lesson-03-derivative/).

**014. Частная производная.** Если входов несколько, меняем один, остальные удерживаем. Для `f(x,y)=x²+3y²` имеем `∂f/∂x=2x`, `∂f/∂y=6y`. Не меняй оба входа одновременно, когда проверяешь одну компоненту. [Код](part-014-lesson-03-partial-derivative/).

**015. Правило цепочки.** Для `f(x)=(2x+1)²` производная внешнего квадрата умножается на производную внутреннего выражения: `2(2x+1)·2`. Пропущенный внутренний множитель `2` меняет ответ. [Код](part-015-lesson-03-chain-rule/).

**016. Градиент.** Собери частные производные в вектор. Для `f(x,y)=(x−2)²+3(y+1)²` он равен `[2(x−2), 6(y+1)]`; в `(2,−1)` обе компоненты нулевые. Градиент направлен к росту функции. [Код](part-016-lesson-03-gradient/).

**017. Численная производная.** Оцени наклон через два близких значения функции, например `(f(x+h)−f(x−h))/(2h)`. Слишком большой `h` даёт грубое приближение, слишком маленький усиливает ошибки округления. [Код](part-017-lesson-03-finite-difference/).

**018. Сводная практика.** Вычисли аналитический градиент и независимо оцени его численно в нескольких точках. Сравнивай с допуском, потому что числа с плавающей точкой и конечный шаг не дают точного совпадения. [Код](part-018-lesson-03-calculus/).

## 04. Градиентный спуск

**019. Скорость обучения.** Новый параметр равен `старый − скорость·градиент`. Для `f(x)=x²`, `x=2`, градиент `4`; при скорости `0.1` следующий `x=1.6`. Большая скорость может перескакивать минимум. [Код](part-019-lesson-04-learning-rate/).

**020. Сходимость.** Следи за историей ошибки и параметра: приближаются ли они к устойчивым значениям? Остановка после фиксированного числа шагов не говорит, найден ли минимум. [Код](part-020-lesson-04-convergence/).

**021. Локальный минимум.** Вблизи такого значения малое изменение входа увеличивает функцию, но в другой области может быть ещё меньший результат. Проверяй несколько начальных точек и сравни конечные значения функции. [Код](part-021-lesson-04-local-minima/).

**022. Batch и stochastic.** Batch считает градиент по всем объектам перед шагом; stochastic использует один объект. Второй путь обычно шумнее: отдельный шаг может увеличить общую ошибку, даже если обучение в целом идёт вперёд. [Код](part-022-lesson-04-batch-stochastic/).

**023. Сводная практика.** Сравни несколько скоростей на одной задаче с одинаковым стартом. Запиши историю ошибки: одного конечного числа мало, чтобы увидеть медленное обучение, колебания или расходимость. [Код](part-023-lesson-04-optimization/).

## 05. Вероятность

**024. Условная вероятность.** `P(A|B)` означает долю случаев `A` среди случаев, где уже произошло `B`. Если из 20 положительных тестов 8 принадлежат больным, `P(болезнь|плюс)=8/20=0.4`. Это не то же, что доля положительных тестов среди больных. [Код](part-024-lesson-05-conditional-probability/).

**025. Независимость.** Если знание `B` не меняет вероятность `A`, события независимы. Тогда `P(A и B)=P(A)·P(B)`. Просто малое число общих случаев ещё не доказывает независимость. [Код](part-025-lesson-05-independence/).

**026. Формула Байеса.** Она пересчитывает вероятность причины после наблюдения. При редкой болезни даже хороший тест может дать много ложных тревог; при расчёте нужна исходная частота болезни. Не подменяй `P(болезнь|плюс)` чувствительностью `P(плюс|болезнь)`. [Код](part-026-lesson-05-bayes/).

**027. Математическое ожидание.** Умножь каждый исход на его вероятность и сложи. При исходах `1` и `3` с вероятностями `0.5` ожидание равно `2`, хотя двойка никогда не выпадает. [Код](part-027-lesson-05-expectation/).

**028. Сводная практика.** Сравни теоретическую вероятность с частотой в моделировании. Доля `fraction=0.25` означает примерно четверть попаданий на длинной серии, но короткая серия не обязана дать ровно 25%. [Код](part-028-lesson-05-probability/).

## 06. Статистика по выборке

**029. Среднее.** Сложи числа и раздели на их количество: для `[1,2,3]` получаем `2`. После добавления `10` среднее становится `4`; крупный выброс сильно сдвигает его. [Код](part-029-lesson-06-mean/).

**030. Медиана.** Отсортируй числа и возьми середину. Для `[1,2,3,10]` медиана `(2+3)/2=2.5`, тогда как среднее `4`. Без сортировки «средний по месту» элемент неверен. [Код](part-030-lesson-06-median/).

**031. Выборочная дисперсия.** Она измеряет разброс относительно среднего. Для `[1,2,3]` среднее `2`, сумма квадратов отклонений `2`, выборочная дисперсия `2/(3−1)=1`. Не дели на `n`, если нужна именно выборочная оценка. [Код](part-031-lesson-06-variance/).

**032. Квантиль.** Это значение в упорядоченной выборке, выбранное по доле от `0` до `1`. В этом уроке индекс равен `floor((n−1)·доля)`: для `[1,3,5,7,9]` и доли `0.75` индекс `3`, ответ `7`. Есть и другие правила расчёта квантилей; сверяй именно правило текущего урока. [Код](part-032-lesson-06-quantile/).

**033. Доверительный интервал.** Интервал описывает неопределённость оценки среднего при повторении процедуры на новых выборках. Уровень 95% относится к доле интервалов, которые накрыли бы неизменное истинное среднее, а не к вероятности для уже построенного фиксированного интервала. [Код](part-033-lesson-06-confidence-interval/).

**034. Bootstrap.** Создавай новые выборки той же длины случайным выбором из исходных данных **с возвращением**. Один объект может повториться, другой не попасть; разброс пересчитанных оценок показывает их устойчивость. [Код](part-034-lesson-06-bootstrap/).

**035. Сводная практика.** В отчёте укажи, какие строки были прочитаны, пропущены или отклонены, а также правило для пропусков. Иначе даже правильно вычисленное среднее нельзя проверить: неизвестно, по каким данным оно получено. [Код](part-035-lesson-06-statistics/).

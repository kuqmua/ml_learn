# Понятия перед кодом: блоки 01–06

Этот конспект читай **до запуска** соответствующего пакета. В каждом пункте есть смысл, маленький расчёт и ошибка, которую легко допустить. После чтения закрой пример, воспроизведи расчёт на бумаге и только потом запускай код. Задание для изменения программы находится в [самопроверке](SELF_CHECK.md).

## 01. Векторы и геометрия

**001. Попарное умножение и сумма.** Берём числа на одинаковых местах: `[1, 2] · [3, 4] = 1·3 + 2·4 = 11`. Знак результата помогает судить об угле ненулевых векторов. Ноль бывает и у перпендикулярных векторов, и при нулевом векторе; эти случаи нужно различать. [Код](part-001-lesson-01-multiply-matching-coordinates-of-two-vectors-then-add/).

**002. Сумма модулей координат одного вектора (норма L1).** Складываем модули координат: для `[-3, 4]` получаем `3 + 4 = 7`. Отрицательная координата не уменьшает длину. Не путай L1 с обычной длиной стрелки. [Код](part-002-lesson-01-sum-absolute-values-of-vector-coordinates/).

**003. Вычисление евклидовой длины одного вектора.** Квадраты координат складываются, затем извлекается корень: `√(3² + 4²) = 5`. Это расстояние от начала координат до конца вектора. Забытый корень дал бы квадрат длины, 25. [Код](part-003-lesson-01-calculate-euclidean-length-of-one-vector/).

**004. Расстояние.** Сначала вычитаем координаты точек, затем берём L2: между `[1, 2]` и `[4, 6]` разность `[3, 4]`, расстояние `5`. Порядок точек на ответ не влияет. [Код](part-004-lesson-01-euclidean-distance-between-two-points/).

**005. Косинусное сходство двух векторов.** Делим скалярное произведение на обе длины. `[1, 0]` и `[2, 0]` дают `1`: направления совпадают, несмотря на разные длины. Для нулевого вектора делить нельзя. [Код](part-005-lesson-01-cosine-similarity-between-two-vectors/).

**006. Сводная практика: скалярное произведение, нормы, расстояние и косинус двух векторов.** Одну пару векторов можно описать разными числами: скалярное произведение учитывает длины и угол, косинус выделяет направление, расстояние сравнивает концы стрелок. Перед вычислением проверь одинаковое число координат. [Код](part-006-lesson-01-practice-vector-dot-product-norms-distance-and-cosine/).

## 02. Матрицы

**007. Проверка числа элементов матрицы и границ строки и столбца.** У матрицы из двух строк по три числа форма `2×3`: сначала строки, потом столбцы. Строка другой длины нарушает прямоугольную форму; перед вычислением это нужно отклонить. [Код](part-007-lesson-02-validate-matrix-element-count-and-row-column-indices/).

**008. Перестановка строк матрицы в столбцы.** Строки становятся столбцами: `[[1, 2, 3], [4, 5, 6]]` превращается в `[[1, 4], [2, 5], [3, 6]]`. Форма `2×3` становится `3×2`. Двойное транспонирование возвращает исходную матрицу. [Код](part-008-lesson-02-transpose-matrix-rows-into-columns/).

**009. Умножение матрицы на вектор через скалярные произведения строк.** Каждая строка даёт одно скалярное произведение: `[[1, 2], [3, 4]] · [5, 6] = [17, 39]`. Число столбцов матрицы должно равняться длине вектора. [Код](part-009-lesson-02-multiply-matrix-by-vector-using-row-dot-products/).

**010. Умножение двух матриц через скалярные произведения строк и столбцов.** Элемент результата — скалярное произведение строки левой и столбца правой матрицы. Для форм `2×3` и `3×4` результат имеет форму `2×4`; внутренние размеры должны совпасть. [Код](part-010-lesson-02-multiply-two-matrices-using-row-column-dot-products/).

**011. Решение системы двух линейных уравнений.** Решение — значения, которые удовлетворяют *обоим* уравнениям. Для `x+y=5`, `x−y=1` получаем `x=3`, `y=2`; подставь их обратно для проверки. Одного верного уравнения недостаточно. [Код](part-011-lesson-02-solve-system-of-two-linear-equations/).

**012. Сводная практика: форма матрицы, транспонирование, произведения и система уравнений.** Храни форму вместе с данными и проверяй её до умножения. Единичная матрица действует как число `1`: `I·A=A`, если формы совместимы. [Код](part-012-lesson-02-practice-matrix-shapes-transpose-products-and-linear-system/).

## 03. Производные

**013. Производная функции одной переменной.** Она показывает локальный наклон функции. Для `f(x)=x²` производная `2x`: в точке `3` наклон `6`, в точке `−2` — `−4`. Нулевая производная сама по себе не доказывает минимум. [Код](part-013-lesson-03-derivative-of-single-variable-function/).

**014. Частная производная функции двух переменных.** Если входов несколько, меняем один, остальные удерживаем. Для `f(x,y)=x²+3y²` имеем `∂f/∂x=2x`, `∂f/∂y=6y`. Не меняй оба входа одновременно, когда проверяешь одну компоненту. [Код](part-014-lesson-03-partial-derivative-of-two-variable-function/).

**015. Правило цепочки для производной композиции функций.** Для `f(x)=(2x+1)²` производная внешнего квадрата умножается на производную внутреннего выражения: `2(2x+1)·2`. Пропущенный внутренний множитель `2` меняет ответ. [Код](part-015-lesson-03-chain-rule-for-derivative-of-composed-functions/).

**016. Градиент функции двух переменных.** Собери частные производные в вектор. Для `f(x,y)=(x−2)²+3(y+1)²` он равен `[2(x−2), 6(y+1)]`; в `(2,−1)` обе компоненты нулевые. Градиент направлен к росту функции. [Код](part-016-lesson-03-gradient-of-two-variable-function/).

**017. Приближение производной функции центральной разностью.** Оцени наклон через два близких значения функции, например `(f(x+h)−f(x−h))/(2h)`. Слишком большой `h` даёт грубое приближение, слишком маленький усиливает ошибки округления. [Код](part-017-lesson-03-approximate-function-derivative-with-central-difference/).

**018. Сводная практика: производные, правило цепочки, градиент и конечные разности.** Вычисли аналитический градиент и независимо оцени его численно в нескольких точках. Сравнивай с допуском, потому что числа с плавающей точкой и конечный шаг не дают точного совпадения. [Код](part-018-lesson-03-practice-derivatives-chain-rule-gradient-and-finite-differences/).

## 04. Градиентный спуск

**019. Скорость обучения в шаге градиентного спуска.** Новый параметр равен `старый − скорость·градиент`. Для `f(x)=x²`, `x=2`, градиент `4`; при скорости `0.1` следующий `x=1.6`. Большая скорость может перескакивать минимум. [Код](part-019-lesson-04-learning-rate-for-gradient-descent-update/).

**020. Сходимость последовательности шагов градиентного спуска.** Следи за историей ошибки и параметра: приближаются ли они к устойчивым значениям? Остановка после фиксированного числа шагов не говорит, найден ли минимум. [Код](part-020-lesson-04-convergence-of-gradient-descent-steps/).

**021. Локальные минимумы невыпуклой функции.** Вблизи такого значения малое изменение входа увеличивает функцию, но в другой области может быть ещё меньший результат. Проверяй несколько начальных точек и сравни конечные значения функции. [Код](part-021-lesson-04-local-minima-of-nonconvex-function/).

**022. Пакетное и стохастическое обновление по градиенту.** Batch считает градиент по всем объектам перед шагом; stochastic использует один объект. Второй путь обычно шумнее: отдельный шаг может увеличить общую ошибку, даже если обучение в целом идёт вперёд. [Код](part-022-lesson-04-batch-versus-stochastic-gradient-updates/).

**023. Сводная практика: скорость обучения, сходимость и режимы градиентного спуска.** Сравни несколько скоростей на одной задаче с одинаковым стартом. Запиши историю ошибки: одного конечного числа мало, чтобы увидеть медленное обучение, колебания или расходимость. [Код](part-023-lesson-04-practice-gradient-descent-learning-rate-convergence-and-update-modes/).

## 05. Вероятность

**024. Условная вероятность одного события при наступлении другого.** `P(A|B)` означает долю случаев `A` среди случаев, где уже произошло `B`. Если из 20 положительных тестов 8 принадлежат больным, `P(болезнь|плюс)=8/20=0.4`. Это не то же, что доля положительных тестов среди больных. [Код](part-024-lesson-05-conditional-probability-of-one-event-given-another/).

**025. Независимость двух событий.** Если знание `B` не меняет вероятность `A`, события независимы. Тогда `P(A и B)=P(A)·P(B)`. Просто малое число общих случаев ещё не доказывает независимость. [Код](part-025-lesson-05-independence-of-two-events/).

**026. Пересчёт вероятности события после наблюдения по формуле Байеса.** Она пересчитывает вероятность причины после наблюдения. При редкой болезни даже хороший тест может дать много ложных тревог; при расчёте нужна исходная частота болезни. Не подменяй `P(болезнь|плюс)` чувствительностью `P(плюс|болезнь)`. [Код](part-026-lesson-05-bayes-update-of-event-probability-after-observation/).

**027. Математическое ожидание дискретных случайных исходов.** Умножь каждый исход на его вероятность и сложи. При исходах `1` и `3` с вероятностями `0.5` ожидание равно `2`, хотя двойка никогда не выпадает. [Код](part-027-lesson-05-expected-value-of-discrete-random-outcomes/).

**028. Сводная практика: условная вероятность, формула Байеса и ожидание.** Сравни теоретическую вероятность с частотой в моделировании. Доля `fraction=0.25` означает примерно четверть попаданий на длинной серии, но короткая серия не обязана дать ровно 25%. [Код](part-028-lesson-05-practice-conditional-probability-bayes-and-expected-value/).

## 06. Статистика по выборке

**029. Среднее арифметическое числовых значений.** Сложи числа и раздели на их количество: для `[1,2,3]` получаем `2`. После добавления `10` среднее становится `4`; крупный выброс сильно сдвигает его. [Код](part-029-lesson-06-arithmetic-mean-of-numeric-values/).

**030. Медиана числовых значений.** Отсортируй числа и возьми середину. Для `[1,2,3,10]` медиана `(2+3)/2=2.5`, тогда как среднее `4`. Без сортировки «средний по месту» элемент неверен. [Код](part-030-lesson-06-median-of-numeric-values/).

**031. Выборочная дисперсия числовых значений.** Она измеряет разброс относительно среднего. Для `[1,2,3]` среднее `2`, сумма квадратов отклонений `2`, выборочная дисперсия `2/(3−1)=1`. Не дели на `n`, если нужна именно выборочная оценка. [Код](part-031-lesson-06-sample-variance-of-numeric-values/).

**032. Квантиль упорядоченных числовых значений.** Это значение в упорядоченной выборке, выбранное по доле от `0` до `1`. В этом уроке индекс равен `floor((n−1)·доля)`: для `[1,3,5,7,9]` и доли `0.75` индекс `3`, ответ `7`. Есть и другие правила расчёта квантилей; сверяй именно правило текущего урока. [Код](part-032-lesson-06-quantile-of-sorted-numeric-values/).

**033. Доверительный интервал для среднего генеральной совокупности.** Интервал описывает неопределённость оценки среднего при повторении процедуры на новых выборках. Уровень 95% относится к доле интервалов, которые накрыли бы неизменное истинное среднее, а не к вероятности для уже построенного фиксированного интервала. [Код](part-033-lesson-06-confidence-interval-for-population-mean/).

**034. Повторные выборки с возвращением из наблюдений.** Создавай новые выборки той же длины случайным выбором из исходных данных **с возвращением**. Один объект может повториться, другой не попасть; разброс пересчитанных оценок показывает их устойчивость. [Код](part-034-lesson-06-bootstrap-resampling-of-observed-values/).

**035. Сводная практика: среднее, медиана и выборочная дисперсия из CSV.** В отчёте укажи, какие строки были прочитаны, пропущены или отклонены, а также правило для пропусков. Иначе даже правильно вычисленное среднее нельзя проверить: неизвестно, по каким данным оно получено. [Код](part-035-lesson-06-practice-mean-median-and-sample-variance-from-csv/).

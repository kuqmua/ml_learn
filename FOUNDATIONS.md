# Понятия перед кодом: блоки 01–06

Этот конспект читай **до запуска** соответствующего пакета. В каждом пункте есть смысл, маленький расчёт и ошибка, которую легко допустить. После чтения закрой пример, воспроизведи расчёт на бумаге и только потом запускай код. Задание для изменения программы находится в [самопроверке](SELF_CHECK.md).

Названия функций объясняют действия над числами. Соответствия формулам и математическим терминам собраны в [памятке по названиям](FUNCTION_NAMES.md).

## 01. Векторы и геометрия

**001. Умножение соответствующих координат двух векторов и сложение результатов.** Берём числа на одинаковых местах: `[1, 2] · [3, 4] = 1·3 + 2·4 = 11`. Знак результата помогает судить об угле ненулевых векторов. Ноль бывает и у перпендикулярных векторов, и при нулевом векторе; эти случаи нужно различать. [Код](l001-01-multiply-matching-coordinates-then-add-results/).

**002. Длина пути вдоль осей (норма L1): сложение модулей координат вектора.** Складываем модули координат: для `[-3, 4]` получаем `3 + 4 = 7`. Отрицательная координата не уменьшает длину. Не путай L1 с обычной длиной стрелки. [Код](l002-01-calculate-l1-vector-norm-by-summing-absolute-coordinates/).

**003. Длина вектора: квадратный корень из суммы квадратов координат.** Квадраты координат складываются, затем извлекается корень: `√(3² + 4²) = 5`. Это расстояние от начала координат до конца вектора. Забытый корень дал бы квадрат длины, 25. [Код](l003-01-calculate-vector-length-as-square-root-of-sum-of-squared-coordinates/).

**004. Квадрат расстояния: сложение квадратов разностей координат.** Для точек `[1, 2]` и `[4, 6]` разности равны `[-3, -4]`, сумма квадратов — `9 + 16 = 25`. Это ещё не расстояние: единицы измерения тоже возведены в квадрат. Перестановка точек меняет знаки разностей, но не результат. Удвоение координат увеличивает сумму в четыре раза. [Код](l004-01-calculate-squared-point-distance-by-summing-squared-coordinate-differences/).

**005. Расстояние между точками: квадратный корень из суммы квадратов разностей координат.** Сначала вычитаем координаты точек, затем берём L2: между `[1, 2]` и `[4, 6]` разность `[3, 4]`, расстояние `5`. Порядок точек на ответ не влияет. [Код](l005-01-calculate-point-distance-as-square-root-of-squared-coordinate-difference-sum/).

**006. Сходство направлений векторов: умножение соответствующих координат, сложение и деление на длины.** Делим скалярное произведение на обе длины. `[1, 0]` и `[2, 0]` дают `1`: направления совпадают, несмотря на разные длины. Для нулевого вектора делить нельзя. [Код](l006-01-calculate-direction-similarity-by-multiplying-coordinates-then-dividing-sum-by-lengths/).

**007. Практика: умножение координат, длины векторов и расстояния между точками.** Одну пару векторов можно описать разными числами: скалярное произведение учитывает длины и угол, косинус выделяет направление, расстояние сравнивает концы стрелок. Перед вычислением проверь одинаковое число координат. [Код](l007-01-practice-multiplying-coordinates-vector-lengths-and-point-distances/).

## 02. Матрицы

**008. Проверка числа элементов матрицы и границ строки и столбца.** У матрицы из двух строк по три числа форма `2×3`: сначала строки, потом столбцы. Строка другой длины нарушает прямоугольную форму; перед вычислением это нужно отклонить. [Код](l008-02-validate-matrix-element-count-and-row-column-indices/).

**009. Транспонирование матрицы: перестановка строк в столбцы.** Строки становятся столбцами: `[[1, 2, 3], [4, 5, 6]]` превращается в `[[1, 4], [2, 5], [3, 6]]`. Форма `2×3` становится `3×2`. Двойное транспонирование возвращает исходную матрицу. [Код](l009-02-transpose-matrix-by-turning-rows-into-columns/).

**010. Умножение матрицы на вектор: умножение соответствующих координат строки и вектора с последующим сложением.** Каждая строка даёт одно скалярное произведение: `[[1, 2], [3, 4]] · [5, 6] = [17, 39]`. Число столбцов матрицы должно равняться длине вектора. [Код](l010-02-multiply-matrix-and-vector-by-adding-multiplied-row-coordinates/).

**011. Умножение двух матриц: умножение соответствующих элементов строк и столбцов с последующим сложением.** Элемент результата — скалярное произведение строки левой и столбца правой матрицы. Для форм `2×3` и `3×4` результат имеет форму `2×4`; внутренние размеры должны совпасть. [Код](l011-02-multiply-matrices-by-adding-multiplied-row-and-column-values/).

**012. Поиск двух неизвестных, удовлетворяющих двум линейным уравнениям.** Решение — значения, которые удовлетворяют *обоим* уравнениям. Для `x+y=5`, `x−y=1` получаем `x=3`, `y=2`; подставь их обратно для проверки. Одного верного уравнения недостаточно. [Код](l012-02-solve-system-of-two-linear-equations/).

**013. Практика: размеры матриц, перестановка строк в столбцы, умножение и решение уравнений.** Храни форму вместе с данными и проверяй её до умножения. Единичная матрица действует как число `1`: `I·A=A`, если формы совместимы. [Код](l013-02-practice-matrix-shapes-row-column-swaps-and-equation-solving/).

## 03. Производные

**014. Производная функции: скорость изменения результата при изменении входа.** Она показывает локальный наклон функции. Для `f(x)=x²` производная `2x`: в точке `3` наклон `6`, в точке `−2` — `−4`. Нулевая производная сама по себе не доказывает минимум. [Код](l014-03-calculate-derivative-as-function-output-change-per-input-change/).

**015. Частная производная: скорость изменения функции при изменении одного из двух входов.** Если входов несколько, меняем один, остальные удерживаем. Для `f(x,y)=x²+3y²` имеем `∂f/∂x=2x`, `∂f/∂y=6y`. Не меняй оба входа одновременно, когда проверяешь одну компоненту. [Код](l015-03-calculate-partial-derivative-by-varying-one-of-two-inputs/).

**016. Производная вложенных функций: умножение скоростей изменения по правилу цепочки.** Для `f(x)=(2x+1)²` производная внешнего квадрата умножается на производную внутреннего выражения: `2(2x+1)·2`. Пропущенный внутренний множитель `2` меняет ответ. [Код](l016-03-calculate-composed-function-derivative-by-multiplying-rates-of-change/).

**017. Градиент: сбор скоростей изменения функции по двум входам в один вектор.** Собери частные производные в вектор. Для `f(x,y)=(x−2)²+3(y+1)²` он равен `[2(x−2), 6(y+1)]`; в `(2,−1)` обе компоненты нулевые. Градиент направлен к росту функции. [Код](l017-03-calculate-gradient-by-collecting-rates-of-change-for-both-inputs/).

**018. Приближённая производная: оценка скорости изменения по значениям слева и справа от точки.** Оцени наклон через два близких значения функции, например `(f(x+h)−f(x−h))/(2h)`. Слишком большой `h` даёт грубое приближение, слишком маленький усиливает ошибки округления. [Код](l018-03-estimate-derivative-from-two-nearby-function-values/).

**019. Практика: скорости изменения функции и их проверка по соседним значениям.** Вычисли аналитический градиент и независимо оцени его численно в нескольких точках. Сравнивай с допуском, потому что числа с плавающей точкой и конечный шаг не дают точного совпадения. [Код](l019-03-practice-rates-of-change-and-checks-with-nearby-values/).

## 04. Градиентный спуск

**020. Шаг уменьшения ошибки: вычитание из параметра произведения размера шага и скорости изменения ошибки.** Новый параметр равен `старый − скорость·градиент`. Для `f(x)=x²`, `x=2`, градиент `4`; при скорости `0.1` следующий `x=1.6`. Большая скорость может перескакивать минимум. [Код](l020-04-reduce-error-by-subtracting-step-size-times-error-slope-from-parameter/).

**021. Повторение обновлений параметра и проверка уменьшения ошибки.** Следи за историей ошибки и параметра: приближаются ли они к устойчивым значениям? Остановка после фиксированного числа шагов не говорит, найден ли минимум. [Код](l021-04-repeat-parameter-updates-and-check-error-decrease/).

**022. Сравнение минимумов функции при движении из разных начальных точек.** Вблизи такого значения малое изменение входа увеличивает функцию, но в другой области может быть ещё меньший результат. Проверяй несколько начальных точек и сравни конечные значения функции. [Код](l022-04-compare-function-valleys-reached-from-different-starts/).

**023. Сравнение обновлений параметра по всем примерам и по одному примеру.** Batch считает градиент по всем объектам перед шагом; stochastic использует один объект. Второй путь обычно шумнее: отдельный шаг может увеличить общую ошибку, даже если обучение в целом идёт вперёд. [Код](l023-04-compare-updates-from-all-examples-and-one-example/).

**024. Практика: выбор размера шага, способа обновления и проверка уменьшения ошибки.** Сравни несколько скоростей на одной задаче с одинаковым стартом. Запиши историю ошибки: одного конечного числа мало, чтобы увидеть медленное обучение, колебания или расходимость. [Код](l024-04-practice-update-step-sizes-and-error-decrease/).

## 05. Вероятность

**025. Вероятность события при известном условии: деление совместной вероятности на вероятность условия.** `P(A|B)` означает долю случаев `A` среди случаев, где уже произошло `B`. Если из 20 положительных тестов 8 принадлежат больным, `P(болезнь|плюс)=8/20=0.4`. Это не то же, что доля положительных тестов среди больных. [Код](l025-05-calculate-conditional-probability-by-dividing-joint-by-known-event-probability/).

**026. Проверка независимости событий: сравнение совместной вероятности с результатом умножения вероятностей.** Если знание `B` не меняет вероятность `A`, события независимы. Тогда `P(A и B)=P(A)·P(B)`. Просто малое число общих случаев ещё не доказывает независимость. [Код](l026-05-check-event-independence-by-comparing-joint-probability-with-multiplied-probabilities/).

**027. Пересчёт вероятности события с учётом частоты полученного наблюдения.** Она пересчитывает вероятность причины после наблюдения. При редкой болезни даже хороший тест может дать много ложных тревог; при расчёте нужна исходная частота болезни. Не подменяй `P(болезнь|плюс)` чувствительностью `P(плюс|болезнь)`. [Код](l027-05-update-event-probability-using-observation-rates/).

**028. Средний ожидаемый результат: сумма значений исходов, умноженных на их вероятности.** Умножь каждый исход на его вероятность и сложи. При исходах `1` и `3` с вероятностями `0.5` ожидание равно `2`, хотя двойка никогда не выпадает. [Код](l028-05-calculate-expected-value-by-summing-outcomes-times-probabilities/).

**029. Практика: пересчёт вероятностей и сумма исходов с весами по вероятности.** Сравни теоретическую вероятность с частотой в моделировании. Доля `fraction=0.25` означает примерно четверть попаданий на длинной серии, но короткая серия не обязана дать ровно 25%. [Код](l029-05-practice-event-probability-updates-and-weighted-outcome-sums/).

## 06. Статистика по выборке

**030. Среднее арифметическое: сложение значений и деление суммы на их количество.** Сложи числа и раздели на их количество: для `[1,2,3]` получаем `2`. После добавления `10` среднее становится `4`; крупный выброс сильно сдвигает его. [Код](l030-06-calculate-mean-by-summing-values-and-dividing-by-count/).

**031. Медиана: поиск среднего по положению значения после сортировки.** Отсортируй числа и возьми середину. Для `[1,2,3,10]` медиана `(2+3)/2=2.5`, тогда как среднее `4`. Без сортировки «средний по месту» элемент неверен. [Код](l031-06-calculate-median-by-sorting-values-and-finding-middle/).

**032. Разброс значений (выборочная дисперсия): сумма квадратов отклонений от среднего, делённая на число значений минус один.** Она измеряет разброс относительно среднего. Для `[1,2,3]` среднее `2`, сумма квадратов отклонений `2`, выборочная дисперсия `2/(3−1)=1`. Не дели на `n`, если нужна именно выборочная оценка. [Код](l032-06-calculate-sample-variance-as-squared-deviation-sum-over-count-minus-one/).

**033. Квантиль: значение на заданной доле упорядоченной выборки.** Это значение в упорядоченной выборке, выбранное по доле от `0` до `1`. В этом уроке индекс равен `floor((n−1)·доля)`: для `[1,3,5,7,9]` и доли `0.75` индекс `3`, ответ `7`. Есть и другие правила расчёта квантилей; сверяй именно правило текущего урока. [Код](l033-06-calculate-quantile-by-selecting-sorted-value-at-given-sample-fraction/).

**034. Доверительный интервал среднего: оценка границ неопределённости по выборке.** Интервал описывает неопределённость оценки среднего при повторении процедуры на новых выборках. Уровень 95% относится к доле интервалов, которые накрыли бы неизменное истинное среднее, а не к вероятности для уже построенного фиксированного интервала. [Код](l034-06-estimate-confidence-interval-as-uncertainty-bounds-around-sample-mean/).

**035. Изменчивость оценки: повторный набор выборок с возвращением наблюдений.** Создавай новые выборки той же длины случайным выбором из исходных данных **с возвращением**. Один объект может повториться, другой не попасть; разброс пересчитанных оценок показывает их устойчивость. [Код](l035-06-estimate-statistic-variability-by-resampling-observations-with-replacement/).

**036. Практика: среднее, середина и квадраты отклонений для данных из CSV.** В отчёте укажи, какие строки были прочитаны, пропущены или отклонены, а также правило для пропусков. Иначе даже правильно вычисленное среднее нельзя проверить: неизвестно, по каким данным оно получено. [Код](l036-06-practice-mean-middle-and-squared-deviations-from-csv/).

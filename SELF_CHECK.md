# Самопроверка после каждого урока

Для каждого пакета сначала предскажи результат или реши задачу на бумаге, затем измени входные данные в коде и запусти `cargo run -p ИМЯ_ПАКЕТА`. Сверь результат с критерием в последнем столбце. Не считай совпадение вывода достаточным, если не можешь объяснить причину.

Перед решением закрой столбец «Как проверить». После проверки поставь себе 2, если решил и объяснил без подсказки, 1, если потребовались подсказки или запуск, и 0, если пока не можешь объяснить ответ. К заданиям с 0 или 1 вернись позже.

## Rust-тест для каждого пакета

В каталоге каждого пакета есть `tests/self_check.rs`. Открой его, реши задание и замени `None` на ответ. Затем запусти тест отдельно:

```bash
cargo test -p part-001-lesson-01-multiply-coordinates-and-add --test self_check -- --ignored --nocapture
```

Подставь имя своего пакета из таблицы ниже. В первом блоке тесты проверяют вычисленные числа и выбранные входы. В уроках 009, 013, 019, 024, 029 и 032 тоже нужно вписать рассчитанные значения; в остальных уроках — выбрать верный критерий результата из трёх вариантов. Тесты помечены `#[ignore]`, поэтому обычный `cargo test --workspace` запускает проверки кода и пропускает нерешённые задания. Ответ на вопрос теста проверяется автоматически; объяснение и изменение программы оцени по столбцу «Как проверить» самостоятельно. Для блоков 01–06 перед заданием можно открыть [пояснения с ручными расчётами](FOUNDATIONS.md).

Задания не меняют порядок курса. Сводные практики проверяют, удалось ли соединить несколько предыдущих идей.

# Самопроверка после каждого урока

Когда выполнишь задание и сможешь объяснить критерий, отметь урок в [списке прогресса](PROGRESS.md).

Для каждого пакета сначала предскажи результат или реши задачу на бумаге, затем измени входные данные в коде и запусти `cargo run -p ИМЯ_ПАКЕТА`. Проверь вычисление через утверждения в коде, тесты и столбец «Как проверить», затем без подсказки объясни смысл по последнему столбцу. Прохождение теста недостаточно, если не можешь объяснить причину.

`cargo run` выполняет пример без консольного вывода. Результаты проверяют утверждения в коде и тесты; уроки с графиками сохраняют SVG в `visualizations/`.

Перед решением закрой столбцы «Как проверить» и «Урок пройден, если…». После проверки поставь себе 2, если решил и объяснил без подсказки, 1, если потребовались подсказки или запуск, и 0, если пока не можешь объяснить ответ. К заданиям с 0 или 1 вернись позже.

## Rust-тест для каждого пакета

В каталоге каждого пакета есть `tests/self_check.rs`. Открой его, реши задание и замени `None` на ответ. Затем запусти тест отдельно:

```bash
cargo test -p l001-01-multiply-matching-coords-then-add-results-where-pos-means-angle-below-90-neg-means-angle-above-90-and-0-means-perpendicular-or-zero-vec --test self_check -- --ignored
```

Подставь имя своего пакета из таблицы ниже. В первом блоке тесты проверяют вычисленные числа и выбранные входы. В уроках 010, 014, 020, 025, 030 и 033 тоже нужно вписать рассчитанные значения; в остальных прежних частях — выбрать верный критерий результата из трёх вариантов. В новых частях 004, 062, 063, 067, 186 и 191 также нужно вписать численный ответ. Тесты помечены `#[ignore]`, поэтому обычный `cargo test --workspace` запускает проверки кода и пропускает нерешённые задания. Ответ на вопрос теста проверяется автоматически; объяснение и изменение программы оцени по двум последним столбцам самостоятельно. Для блоков 01–06 перед заданием можно открыть [пояснения с ручными расчётами](FOUNDATIONS.md).

Критерий считается выполненным, когда можешь объяснить его своими словами и подтвердить маленьким примером без чтения готового ответа. Если получается только повторить фразу, вернись к коду и поменяй входные данные. Задания не меняют порядок курса. Сводные практики проверяют, удалось ли соединить несколько предыдущих идей.

## Автоматические проверки кода и структуры

`cargo test --workspace` запускает обычные проверки кода. В новых частях 004, 062, 063, 067, 186 и 191 файл `tests/behavior.rs` проверяет результаты, граничные случаи и свойства операций; он не требует заполнения ответов. Часть 005 отдельно проверяет расстояние после извлечения корня.

`cargo test -p lesson-structure --test lesson_structure` разбирает Rust-код всех частей и проверяет, что каждая публичная учебная функция имеет прямой вызов в `main` своего крейта. Упоминания в комментариях, строках, тестах и неиспользуемых вспомогательных функциях не засчитываются. Проверка структуры не заменяет численные тесты.

# Самопроверка после каждого урока

Когда выполнишь задание и сможешь объяснить критерий, отметь урок в [списке прогресса](PROGRESS.md).

Для каждого пакета сначала предскажи результат или реши задачу на бумаге, затем измени входные данные в коде и запусти `cargo run -p ИМЯ_ПАКЕТА`. Сверь результат со столбцом «Как проверить», затем без подсказки объясни смысл по последнему столбцу. Совпадения вывода недостаточно, если не можешь объяснить причину.

При `cargo run` строки с префиксом `[XXX-YY]` показывают промежуточные значения переменных этого урока и вызванных им уроков. В длинных циклах видны первые четыре повтора, затем 8-й, 64-й, 512-й и так далее; длинные значения и общий вывод ограничены, чтобы итог примера не потерялся. Расчёты для построения графика в этот вывод не входят.

Перед решением закрой столбцы «Как проверить» и «Урок пройден, если…». После проверки поставь себе 2, если решил и объяснил без подсказки, 1, если потребовались подсказки или запуск, и 0, если пока не можешь объяснить ответ. К заданиям с 0 или 1 вернись позже.

## Rust-тест для каждого пакета

В каталоге каждого пакета есть `tests/self_check.rs`. Открой его, реши задание и замени `None` на ответ. Затем запусти тест отдельно:

```bash
cargo test -p l001-01-calculate-scalar-product-by-multiplying-matching-coordinates-and-adding --test self_check -- --ignored --nocapture
```

Подставь имя своего пакета из таблицы ниже. В первом блоке тесты проверяют вычисленные числа и выбранные входы. В уроках 009, 013, 019, 024, 029 и 032 тоже нужно вписать рассчитанные значения; в остальных уроках — выбрать верный критерий результата из трёх вариантов. Тесты помечены `#[ignore]`, поэтому обычный `cargo test --workspace` запускает проверки кода и пропускает нерешённые задания. Ответ на вопрос теста проверяется автоматически; объяснение и изменение программы оцени по двум последним столбцам самостоятельно. Для блоков 01–06 перед заданием можно открыть [пояснения с ручными расчётами](FOUNDATIONS.md).

Критерий считается выполненным, когда можешь объяснить его своими словами и подтвердить маленьким примером без чтения готового ответа. Если получается только повторить фразу, вернись к коду и поменяй входные данные. Задания не меняют порядок курса. Сводные практики проверяют, удалось ли соединить несколько предыдущих идей.

# Как читать названия функций

В уроках имя функции сначала объясняет, **что получаем**, затем — **как это вычисляем**. Используем форму `calculate_<результат>_by_<действия>` или `calculate_<результат>_as_<формула>`. Математический термин и пояснение формулы стоят перед определением.

Например, `calculate_vector_length_as_square_root_of_sum_of_squared_coordinates` читается как «вычислить длину вектора как квадратный корень из суммы квадратов координат». Для `[3, 4]` это `sqrt(3² + 4²) = 5`. Математический термин — **евклидова норма**, или **длина вектора**.

- Для короткой формулы указываем результат и операции: например, длина вектора — корень из суммы квадратов, среднее — сумма, делённая на количество.
- Для большого алгоритма указываем назначение и основные действия: например, вычисление контекста через взвешенное сложение значений.
- Функции `plot_...` строят графики; имя связывает показанную величину со способом её вычисления, когда это помогает понять результат.
- `main` остаётся стандартной точкой входа Rust. Имена, которые уже объясняют результат и действие, например `generate_random_number_between_zero_and_one`, сохраняются.

Названия уроков, пакетов и каталогов тоже связывают результат со способом его получения. Например: «Длина вектора: квадратный корень из суммы квадратов координат». Эти названия согласованы с планом курса. Принятые математические термины сохранены в пояснениях к коду. В уроках без отдельных вычислительных функций операции находятся непосредственно в `main`.

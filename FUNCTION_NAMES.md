# Как читать названия функций

В уроках имя функции описывает действие: что сделать с входными значениями и какой результат получить. Математическое название и формула стоят в комментарии перед определением.

Например, `square_root_of_sum_of_squared_coordinates` читается как «квадратный корень из суммы квадратов координат». Для `[3, 4]` это `sqrt(3² + 4²) = 5`. Математический термин — **евклидова норма**, или **длина вектора**.

- Для короткой формулы называем операции: сложить, умножить, разделить, извлечь корень.
- Для большого алгоритма называем его основные действия; подробности и принятые термины объясняем рядом с кодом.
- Функции `plot_...` строят графики; окончание имени описывает именно показанные данные.
- `main` остаётся стандартной точкой входа Rust. Уже понятные имена, например `multiply_number_by_itself`, сохраняются.

Названия уроков, пакетов и каталогов также описывают действия и согласованы с планом курса. Принятые математические термины сохранены в пояснениях к коду. В уроках без отдельных вычислительных функций операции находятся непосредственно в `main`.

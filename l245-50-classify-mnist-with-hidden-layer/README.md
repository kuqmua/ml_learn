# 245 · MNIST: Нейросеть с одним скрытым слоем

Добавь нелинейность к линейному классификатору. Архитектура: 784 → Dense(128) → ReLU → Dense(10), всего 101 770 параметров.

Скрытый слой учится создавать сочетания пикселей. ReLU заменяет отрицательные значения нулём. Без ReLU композиция двух линейных преобразований снова была бы одним линейным преобразованием, поэтому ширина сама по себе не решает проблему.

Прямой проход: `hidden = ReLU(XW1+b1)`, `scores = hidden W2+b2`. Обратный проход идёт от cross-entropy через второй Dense, маску ReLU и первый Dense. Градиенты обоих слоёв вычисляются по старым весам, затем Adam меняет оба слоя. Открой функцию `main` в `src/main.rs`, чтобы увидеть этот порядок явно.

## Запуск

Из корня workspace:

```bash
python3 scripts/prepare_mnist.py
cargo run --release -p l245-50-classify-mnist-with-hidden-layer
cargo run --release -p l245-50-classify-mnist-with-hidden-layer -- --self-check
```

По умолчанию: 15 эпох, batch-size 64, learning-rate 0.001, seed 42, полный train. Обучение идёт на CPU. Используй `--release`: особенно для CNN разница во времени существенна.

[Правила эксперимента и сравнение моделей](../MNIST.md) описывают загрузку PNG, разделение данных, Adam и все флаги. Метка берётся из имени папки, 784 пикселя нормализуются делением на 255. Каждый пятый PNG каждого класса используется для validation; test не участвует в обучении и выборе эпохи.

Вывод содержит train loss, validation loss и accuracy по эпохам, выбранную по validation loss эпоху, итоговый test, baseline и матрицу ошибок. Результат не гарантирован одной архитектурой: важны данные, скорость обучения и число эпох.

## Самостоятельное задание

1. Для входов ReLU [-2,0,3] и входящего градиента [4,5,6] вычисли выход и обратный градиент.
2. Объясни, почему два Dense без ReLU эквивалентны одному Dense.
3. Запусти полный опыт. Сравни loss и accuracy с линейной моделью, используя одинаковые части данных.
4. Измени число скрытых нейронов (и размер входа выходного слоя) на 64 или 256. Выбирай вариант по validation, запиши число параметров.
5. Найди эпохи, где train loss продолжает падать, а validation loss растёт. Объясни, какую копию модели runner использует для итогового test.
6. Ответь на вопрос в блоке `if exercise` внутри `main`, замени `None` на `Some(ответ)` и запусти `cargo run --release -p l245-50-classify-mnist-with-hidden-layer -- --exercise`.

Урок пройден, если можешь объяснить прямой и обратный проход модели, какие параметры обучаются, почему выбор эпохи идёт по validation и как проверить метрику на настоящих PNG.

Проверенный полный запуск с настройками по умолчанию: **97,72% accuracy на test**. [Сравнение и журналы запусков](../MNIST.md#проверенный-запуск-на-полном-mnist).

В уроке объявлена только функция `main`: загрузка PNG, числовые операции, параметры, обучение и оценка находятся внутри неё. Для повторяющихся операций используются локальные замыкания. `--self-check` выполняет проверки PNG и вычислений, затем короткое обучение на синтетических данных без скачивания датасета. `--exercise` запускает самостоятельный вопрос после заполнения ответа в коде.

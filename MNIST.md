# MNIST: самостоятельные уроки на PNG

В уроках 243–246 весь Rust-код находится **внутри функции `main`** файла `src/main.rs` каждого пакета: чтение PNG, модель, обучение и оценка. Отдельных функций, моделей с методами, общих крейтов и подключаемых файлов исходного кода нет. Повторяющиеся операции записаны как локальные замыкания внутри `main`. Каждый урок можно читать целиком. Внутри одного урока общие операции объявлены один раз и переиспользуются на разных этапах.

Метка картинки имеет тип `Digit` — enum с вариантами `Zero`, `One`, …, `Nine`. Запись датасета: `([f64; 784], Digit)`, например `(pixels, Digit::Seven)`. Метки в batch и предсказания также используют `Digit`. Для индексации матриц вариант преобразуется через `digit as usize`; порядок вариантов соответствует цифрам 0–9. `u8` используется для сырых яркостей PNG (0–255).

Подготовка PNG: `python3 scripts/prepare_mnist.py`. Декодирование выполняет внешний crate `png`, матричные умножения в уроках 244–246 — `ndarray`. Обучение работает на CPU.

## Области видимости внутри main

Код разделён на блоки, которые возвращают только нужные следующему этапу результаты. PNG-декодер, разделение данных, инициализация весов, обучение и итоговая оценка имеют отдельные области видимости.

В нейросетевых уроках из обучения выходят выбранные веса, номер эпохи и размер batch. Счётчики классов, индексы train/validation, генератор перемешивания, начальные веса и состояние Adam остаются внутри обучения. При расчёте градиентов активации и промежуточные производные локальны одному batch; поправки Adam — блоку обновления параметров. Помощники прямого прохода объявлены внутри его замыкания. Один `batch` используется обучением и оценкой, `argmax` остаётся внутри оценки. Общий `next_random` используется перемешиванием и инициализацией весов; состояние генератора передаётся явно, поэтому порядок случайных чисел сохраняется.

В уроке 243 средние изображения вычисляются до объявления `evaluate_digit_predictions`. Замыкание заимствует готовую модель из окружающего блока; передавать её параметром не нужно. Счётчики обучения остаются внутри блока вычисления средних. Загрузчик объявлен один раз в начале `main` и вызывается для train и test во всех четырёх уроках. В уроке 243 `evaluate_digit_predictions` предсказывает цифры и печатает точность для validation и test. Области видимости данных и счётчиков остаются отдельными.

Изменяемые временные значения ограничены этапом построения результата. В загрузчике `mut paths` существует только при сборе и сортировке файлов; декодер и `mut pixels` — внутри чтения одного PNG. Дальше используются неизменяемые пути и байты. Аналогично накопители метрик и сумм пикселей, окна свёрток и перепакованные градиенты возвращаются из своих блоков без `mut`.

В нейросетевых уроках начальные веса и моменты Adam создаются как неизменяемые результаты. Изменяемые веса, индексы train, генератор, моменты Adam и выбор лучшей эпохи локальны блоку цикла обучения. Из него выходят только неизменяемые `best` и `best_epoch`; сумма train loss локальна обходу batch одной эпохи. В уроке 243 `mut means` существует только при усреднении пикселей. Накопители, которым нужно изменяться до самого возврата из замыкания, остаются локальны этому замыканию.

## Правила эксперимента

PNG сортируются по имени внутри каждого класса. Каждый пятый пример каждого класса попадает в validation, остальные — в train. Все четыре урока используют одинаковые части: 47 995 train и 12 005 validation. Официальные 10 000 test остаются отдельными. Seed 42 определяет начальные веса и порядок перемешивания train; разделение от seed не зависит.

В уроках 244–246 batch-size 64. Последний неполный batch тоже обучается; градиент cross-entropy делится на его фактический размер. После каждой эпохи выводятся средняя train loss (во время обновлений), validation loss и accuracy. В памяти сохраняется копия модели с наименьшей validation loss, включая начальную модель. Test загружается после выбора эпохи и оценивается один раз.

Запуск из папки выбранного урока:

```bash
cargo run
```

Из корня workspace можно выбрать урок через `cargo run -p ИМЯ_УРОКА`. Аргументы программе не нужны. Оптимизация для этих уроков и библиотек вычислений настроена в корневом `Cargo.toml`, поэтому обычный запуск подходит для обучения на CPU.

Путь к PNG и параметры заданы в начале `main`: `data`, `epochs`, `batch_size`, `learning_rate`, `seed`. Для экспериментов меняй значения в коде и снова запускай урок. В уроке 243 нужен только путь `data`. Все уроки читают `datasets/png/mnist` с папками `train/0` … `train/9` и `test/0` … `test/9`.

Для сравнения гиперпараметров смотри validation, а итоговый test используй после принятия решения. Повторный подбор параметров по test нарушает смысл независимой оценки. Веса хранятся только в памяти текущего процесса; команда повторно обучает модель. Полный отчёт можно сохранить перенаправлением stdout в файл.

## Математика общего кода

Dense: `Z = XW + b`, `dX = dZ Wᵀ`, `dW = Xᵀ dZ`, `db = sum_rows(dZ)`. Производная ReLU пропускает градиент только при положительном входе; в нуле выбирается 0.

Softmax рассчитывается после вычитания максимального score. Cross-entropy использует log-sum-exp; градиент по scores — `(probability - one_hot(target))/batch`. Это избавляет от отдельного вычисления полного якобиана softmax. Все градиенты модели вычисляются до обновления весов.

Adam хранит экспоненциальные средние градиентов и их квадратов: β₁=0.9, β₂=0.999, ε=1e-8. После поправки на начальные нули обновляет параметр на `learning_rate * m_hat/(sqrt(v_hat)+epsilon)`. Веса и смещения всех слоёв обучаются; веса инициализируются равномерно с дисперсией `2/fan_in`, смещения — нулями.

Conv2d — valid-свёртка, шаг 1, без дополнения границ. Каждое окно становится строкой im2col и умножается на общую матрицу фильтров. При обратном проходе градиенты перекрывающихся окон **суммируются** в исходных пикселях. Max-pool 2×2 с шагом 2 запоминает индекс максимума и отправляет градиент только туда; при равных максимумах выбирается первый.

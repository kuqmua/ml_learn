# MNIST: самостоятельные уроки на PNG

В уроках 243–246 весь Rust-код находится **внутри функции `main`** файла `src/main.rs` каждого пакета: чтение PNG, модель, обучение, оценка, автоматические проверки и самостоятельное задание. Отдельных функций, моделей с методами, общих крейтов и подключаемых файлов исходного кода нет. Повторяющиеся операции записаны как локальные замыкания внутри `main`. Загрузчик и необходимые операции повторены в уроках, чтобы каждый можно было читать целиком.

Подготовка PNG: `python3 scripts/prepare_mnist.py`. Декодирование выполняет внешний crate `png`, матричные умножения в уроках 244–246 — `ndarray`. Обучение работает на CPU.

## Области видимости внутри main

Код разделён на блоки, которые возвращают только нужные следующему этапу результаты. Разбор аргументов, PNG-декодер и его проверки, разделение данных, инициализация весов, обучение и итоговая оценка имеют отдельные области видимости.

В нейросетевых уроках из обучения выходят выбранные веса, номер эпохи, класс baseline и размер batch. Счётчики классов, индексы train/validation, генератор перемешивания, начальные веса и состояние Adam остаются внутри обучения. При расчёте градиентов активации и промежуточные производные локальны одному batch; поправки Adam — блоку обновления параметров. Помощники прямого прохода объявлены внутри его замыкания, а подготовка batch и argmax для оценки — внутри замыкания оценки.

В уроке 243 из обучения и проверки validation выходят только средние изображения и класс baseline. Данные train и их счётчики не видны в блоке test. Декодер PNG объявляется локально в каждом блоке загрузки; ни один этап не передаёт его дальше вместе с данными.

## Правила эксперимента

PNG сортируются по имени внутри каждого класса. Каждый пятый пример каждого класса попадает в validation, остальные — в train. Все четыре урока используют одинаковые части: 47 995 train и 12 005 validation. Официальные 10 000 test остаются отдельными. Seed по умолчанию 42 определяет начальные веса и порядок перемешивания train; разделение от seed не зависит.

В уроках 244–246 batch-size по умолчанию 64. Последний неполный batch тоже обучается; градиент cross-entropy делится на его фактический размер. После каждой эпохи выводятся средняя train loss (во время обновлений), validation loss и accuracy. В памяти сохраняется копия модели с наименьшей validation loss, включая начальную модель. Test загружается после выбора эпохи и оценивается один раз. Baseline — самый частый класс train.

Настройки командной строки:

```bash
cargo run --release -p l245-50-classify-mnist-with-hidden-layer -- --epochs 15 --batch-size 64 --learning-rate 0.001 --seed 42
```

`--data PATH` задаёт корень с папками `train/0` … `train/9` и `test/0` … `test/9`. `--train-limit N` ограничивает только train после перемешивания, validation/test остаются полными. Это быстрый опыт с меньшим объёмом обучения; сравнивать его результат с полным обучением нужно с указанием N. В ограниченном train должны присутствовать все десять классов. Пример короткого запуска:

```bash
cargo run --release -p l246-51-classify-mnist-with-convolutional-network -- --epochs 1 --train-limit 2000
```

Для сравнения гиперпараметров смотри validation, а итоговый test используй после принятия решения. Повторный подбор параметров по test нарушает смысл независимой оценки. Веса хранятся только в памяти текущего процесса; команда повторно обучает модель. Полный отчёт можно сохранить перенаправлением stdout в файл.

## Математика общего кода

Dense: `Z = XW + b`, `dX = dZ Wᵀ`, `dW = Xᵀ dZ`, `db = sum_rows(dZ)`. Производная ReLU пропускает градиент только при положительном входе; в нуле выбирается 0.

Softmax рассчитывается после вычитания максимального score. Cross-entropy использует log-sum-exp; градиент по scores — `(probability - one_hot(target))/batch`. Это избавляет от отдельного вычисления полного якобиана softmax. Все градиенты модели вычисляются до обновления весов.

Adam хранит экспоненциальные средние градиентов и их квадратов: β₁=0.9, β₂=0.999, ε=1e-8. После поправки на начальные нули обновляет параметр на `learning_rate * m_hat/(sqrt(v_hat)+epsilon)`. Веса и смещения всех слоёв обучаются; веса инициализируются равномерно с дисперсией `2/fan_in`, смещения — нулями.

Conv2d — valid-свёртка, шаг 1, без дополнения границ. Каждое окно становится строкой im2col и умножается на общую матрицу фильтров. При обратном проходе градиенты перекрывающихся окон **суммируются** в исходных пикселях. Max-pool 2×2 с шагом 2 запоминает индекс максимума и отправляет градиент только туда; при равных максимумах выбирается первый.

## Проверка внутри main

```bash
cargo run --release -p l243-48-classify-mnist-digits-by-nearest-class-mean -- --self-check
cargo run --release -p l244-49-classify-mnist-with-linear-softmax -- --self-check
cargo run --release -p l245-50-classify-mnist-with-hidden-layer -- --self-check
cargo run --release -p l246-51-classify-mnist-with-convolutional-network -- --self-check
```

Этот режим не требует MNIST. Временные PNG проверяют чтение, нормализацию, метки, сортировку, отказ при повреждениях и неправильной форме. В нейросетевых уроках конечные разности проверяют Dense и cross-entropy, а в CNN также веса, смещения и вход многоканальной свёртки. Проверяются ReLU, pooling, воспроизводимость и учёт неполных batch при оценке. Затем тот же цикл обучения работает на синтетических изображениях: ошибка должна снизиться, веса каждого слоя — измениться. В уроке 243 проверяются средние изображений и правильные прогнозы на синтетических классах.

Для самостоятельного вопроса найди `if exercise` внутри `main`, замени `None` на `Some(ответ)` и запусти `cargo run --release -p ИМЯ_УРОКА -- --exercise`. До заполнения ответ намеренно вызывает ошибку. `cargo test` больше не запускает проверки этих четырёх уроков: вся их логика находится в `main`, включая проверки.

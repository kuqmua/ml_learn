# 243 · MNIST: распознавание рукописных цифр

Цель: пройти путь от настоящих изображений до обучения и оценки классификатора на Rust. Разделение данных, обучение и оценка находятся в функции `main` файла `src/main.rs`; чтение PNG и тип `Digit` переиспользуются из общего crate `mnist_data`. [Правила работы с данными и сравнение моделей](../MNIST.md). Полезно после блоков 01 (расстояния), 07 (разделение), 11 (метрики) и 24 (изображения).

Из папки урока (PNG достаточно подготовить один раз):

```bash
python3 ../scripts/prepare_mnist.py
cargo run
```

Python нужен только для скачивания, распаковки и экспорта PNG. Скрипт проверяет SHA-256 архивов, заголовки IDX, размер файлов и метки. Повторный запуск использует локальные архивы; Rust читает PNG из `datasets/png/mnist/` без сети. Данные лежат в игнорируемом Git каталоге `datasets/`. При отсутствии данных программа выводит команду подготовки.

MNIST содержит изображения 28×28 с метками 0–9: 60 000 исходных обучающих и 10 000 тестовых примеров. Источник: [страница авторов](https://yann.lecun.org/exdb/mnist/), [описание TensorFlow Datasets](https://www.tensorflow.org/datasets/catalog/mnist). Загрузка идёт с зеркала `storage.googleapis.com/cvdf-datasets/mnist`, контрольные суммы взяты из [TensorFlow Datasets](https://github.com/tensorflow/datasets/blob/master/tensorflow_datasets/url_checksums/mnist.txt). Авторы MNIST: Yann LeCun, Corinna Cortes и Christopher J. C. Burges.

Загрузчик обходит папки `train/0` … `train/9` и `test/0` … `test/9`, берёт метку из имени папки и сортирует имена PNG внутри каждого класса. Проверяет формат: статическое изображение 28×28, 8-битные оттенки серого. Ошибка чтения содержит путь к картинке.

Каждое изображение превращается в 784 числа от 0 до 1: байт пикселя делится на 255. Это фиксированное преобразование, оно не обучается на test. Чёрный фон близок к 0, светлый штрих — к 1.

Каждый пятый PNG каждого класса в порядке имён файлов из исходного train попадает в validation, остальные — в train. Правило детерминированное, случайный seed не используется. Официальный test остаётся отдельным. Для каждой цифры программа суммирует обучающие изображения и делит на число примеров этой цифры. Получается десять средних изображений. Прогноз — класс, чьё среднее изображение ближе всего по сумме квадратов разностей пикселей. При равных расстояниях выбирается меньшая цифра.

Программа печатает размеры частей, accuracy модели на validation и test, затем матрицу ошибок test. В матрице строки — истинные цифры, столбцы — предсказанные. Это простая модель: среднее размывает варианты почерка, а расстояние чувствительно к сдвигу изображения. Высокое качество нейросети здесь не предполагается.

Самостоятельное задание:

1. Открой `datasets/png/mnist/train/5/00000.png` и сравни изображение с меткой папки. До запуска объясни, что означают 784 координаты и чему равны нормализованные пиксели 0, 128 и 255.
2. Найди в коде границу между обучением и оценкой. Объясни, почему validation и test не должны менять средние изображения.
3. По матрице ошибок найди наиболее частую пару перепутанных цифр. Различай ошибку 4→9 и 9→4.
4. Добавь вариант признаков: среднее значение каждого квадрата 2×2 (14×14 координат). Сравни варианты на validation, выбери один, затем сформируй итоговый отчёт на test. Не выбирай признаки по test.

Урок пройден, если можешь объяснить нормализацию, обучение средних, назначение трёх частей и смысл одного элемента матрицы ошибок.

### Просмотр MNIST в PNG

Команда `python3 scripts/prepare_mnist.py` из корня workspace создаёт все 70 000 изображений PNG в `datasets/png/mnist/`: `train/0/` … `train/9/` и `test/0/` … `test/9/`. Имя папки — правильная цифра, имя файла — индекс в исходном наборе (например, `train/5/00000.png`). Открой папку в файловом менеджере и включи миниатюры или открой любой PNG просмотрщиком. Изображения сохраняют исходные 28×28 пикселей и оттенки серого; для крупного просмотра увеличь масштаб. Rust-урок обучается непосредственно на этих PNG. IDX остаются промежуточными файлами подготовки; для запуска урока они не нужны.

Продолжение: [244 — линейный softmax](../l244-49-classify-mnist-with-linear-softmax/README.md), [245 — скрытый слой](../l245-50-classify-mnist-with-hidden-layer/README.md), [246 — CNN](../l246-51-classify-mnist-with-convolutional-network/README.md).

В уроке объявлена только функция `main`: числовые операции, параметры, обучение и оценка находятся внутри неё. Загрузчик PNG и тип `Digit` импортируются из [mnist_data](../mnist-data/src/lib.rs). Для повторяющихся операций используются локальные замыкания. Путь к данным и настройки заданы в коде. Запуск без аргументов загружает MNIST, обучает модель и выводит метрики.

Счётчики, суммы яркостей и средние изображения хранятся в структуре `DataByDigit<T>` с десятью полями `zero` … `nine`. Например, `training_image_count_by_digit.seven` — число обучающих семёрок, а `mean_image_by_digit.seven` — их среднее изображение. `T` задаёт тип содержимого: `usize` для счётчиков или `[f64; 784]` для изображения. Нужное поле выбирается через `match` по `Digit`. Структура объявлена внутри `main`.

Внутри проверки формируется список `Vec<DigitPrediction>`. Каждая запись содержит `actual_digit` (правильную цифру) и `predicted_digit` (ответ модели). Точность считается по совпадениям этих полей, число проверенных картинок — по длине списка. Код вывода таблицы ошибок по парам цифр сохранён закомментированным.

`evaluate_digit_predictions` объявлено после обучения и заимствует `mean_image_by_digit` из окружающего блока. Для validation и test используется одна готовая модель; единственный аргумент замыкания — готовый набор картинок с правильными ответами.

До обучения формируются три отдельных списка: `train_images`, `validation_images` и `test_images`. Исходный train разделяется через фильтры: каждая пятая картинка каждой цифры попадает в validation, остальные — в train. Test загружается из своей папки. Обучение обходит только `train_images`, а предсказание — весь переданный набор без индексов.

Вывод точности находится внутри `evaluate_digit_predictions`: отдельного замыкания `print_prediction_report` нет. Проверка вызывается напрямую для `validation_images` и `test_images`.
